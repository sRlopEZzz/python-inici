# Projeto Python – Ferramenta de Apoio à Decisão

Unidade Curricular: Gestão de Sistemas de Informação (2023/2024)
Autor: Leandro Lopes Vieira

Descrição
Este projeto foi desenvolvido no âmbito da unidade curricular Gestão de Sistemas de Informação e tem como objetivo a criação de uma ferramenta de apoio à decisão (DSS) utilizando Python.

O sistema analisa dados da empresa fictícia “Sempre a Vender”, permitindo extrair informação relevante para apoiar a tomada de decisão dos gestores.

Estrutura do Projeto
Main.py – Ficheiro principal de execução
Clientes.py – Análise de clientes
Produtos.py – Análise de produtos e categorias
Vendas.py – Análise de vendas
Compras.py – Informação sobre compras
Entregas.py – Análise de entregas
Metodo_pagamento.py – Análise de métodos de pagamento

Dados Utilizados
customer_details.csv
products_details.csv
sales.csv

Tecnologias
Python
Pandas
PyCharm
Git / GitHub
